# Real-world analogs

Real pidgins, creoles and contact languages used as **points of reference, not models to copy.** The developer's framing (2026-10-13): Hawaiʻi Creole English will not be a one-to-one match for Modern Hawaiian, but it is a good place to start.

| Language | Why it matters | Folder | Status |
|---|---|---|---|
| Hawaiʻi Creole English ("Pidgin") | Same islands, same kind of contact: plantation pidgin (reported start 1835) that nativized into a first language by the early 20th century; vocabulary mostly English, with Hawaiian, Cantonese, Portuguese, Japanese and later Ilocano, Okinawan and Korean features. Standard description: Sakoda & Siegel, *Pidgin Grammar* (2003). | `Hawaii_Creole_English/` | first searches done 2026-10-13 |
| Tok Pisin | A pidgin that became a national language and a first language; documented expansion of vocabulary and grammar. | `Tok_Pisin/` | not started |
| Swahili | A contact-influenced national language (Bantu grammar, heavy Arabic vocabulary). *Not* a pidgin of Arabic, French and Persian: the draft's comparison was corrected 2026-10-13. | `Swahili/` | not started |
| Others to consider | Chavacano, Sranan, Haitian Creole, Michif, Singapore English, Nigerian Pidgin | none | not started |

Each analog gets a folder with the same shape as `contributing_languages/_TEMPLATE/`, plus a section **"What transfers to Modern Hawaiian, and what does not."**
